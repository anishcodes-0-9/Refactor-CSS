# Refactor-CSS

A conservative, evidence-based CSS usage analyzer for React/Next.js repositories.

**Status:** pre-release scaffold (v0.1 in progress). No analysis functionality is implemented yet.

See [`docs/adr-001-v0.1-architecture.md`](docs/adr-001-v0.1-architecture.md) for the binding v0.1
architecture, [`docs/architecture-review.md`](docs/architecture-review.md) for the full design
rationale, and [`docs/research-origin.md`](docs/research-origin.md) for the real-world failure
modes that motivated this project.
